Школа 21 // Проект 01

«Умный город» — Observability Stack

Архитектура и реализация:

  • Развертывание многоконтейнерной инфраструктуры в кластере Docker Swarm с изолированными сетями и персистентными томами.
  • Настройка Prometheus для сбора метрик, Grafana для визуализации дашбордов, Grafana Loki для агрегации логов.
  • Динамическое Service Discovery через dns_sd_configs для автоматического сбора метрик с Node Exporter, cAdvisor и Blackbox Exporter.

Сниппеты и алертинг:

groups:
  - name: node_alerts
    rules:
      - alert: HighCPUUsage
        expr: 100 - (avg by(instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 85
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "High CPU usage detected on {{ $labels.instance }}"

Итоговый результат:

Развернута централизованная система мониторинга с интерактивными дашбордами в Grafana и мгновенной доставкой критических инцидентов через Prometheus Alertmanager и Telegram Bot API. Работоспособность подтверждена стресс-тестированием.

Школа 21 // Проект 02

Автоматизация CI/CD пайплайнов

Архитектура конвейера:

  • Проектирование многостадийного конвейера в GitLab CI/CD (Build, Test, Deploy).
  • Интеграция автоматической компиляции проектов на C с помощью Make и статического анализатора clang-format с флагом --Werror.
  • Автоматический прогон юнит-тестов и безопасный деплой по SSH/SCP на целевой сервер.

gitlab-ci.yml:

stages:
  - build
  - test
  - deploy

build_job:
  stage: build
  script:
    - make clean && make
  artifacts:
    paths:
      - ./bin/

test_job:
  stage: test
  script:
    - make test

Итоговый результат:

Внедрен полноценный CI/CD конвейер со строгим контролем стиля кода, автоматической сборкой и мгновенными уведомлениями в Telegram о статусах деплоя.

ООО "Амнис-Групп" // Production

Производственная инфраструктура и сетевая безопасность

Зона ответственности и задачи:

  • Администрирование серверов, настройка регулярного резервного копирования критических баз данных и Active Directory.
  • Поддержка локальной сети (LAN, Wi-Fi), настройка безопасных VPN-туннелей для удаленных сотрудников.
  • Разработка Bash-скриптов для автоматической перенастройки сетевых параметров при миграции на новые серверные мощности.

Bash Automation Example:

#!/bin/bash
# Network migration helper script
BACKUP_DIR="/var/backups/network"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR
cp /etc/netplan/*.yaml $BACKUP_DIR/netplan_$DATE.bak
echo "[INFO] Network configs backed up successfully at $DATE"

Итоговый результат:

Сокращение простоя при миграции на 70–80%, ускорение диагностики аппаратных сбоев на 40%, экономия более 230 000 рублей за счет модульного ремонта оборудования своими силами, NPS 100%.
